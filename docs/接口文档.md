# 接口文档

所有接口前缀 `/api`，请求头需带 `Authorization: Bearer <token>`（登录接口除外）。

## 认证

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/login` | 微信登录，body: `{code, nickname, avatar, role, grade}`，返回 `{token, user}` |
| POST | `/auth/admin-login` | 管理后台登录，body: `{username, password}` |
| GET | `/auth/me` | 当前用户信息（含班级） |
| POST | `/auth/profile` | 更新资料 `{nickname, avatar, role, grade}` |
| POST | `/auth/become-teacher` | 升级为老师 `{secret}` |

## 班级

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/class` | 创建班级（老师）`{name, grade}` |
| POST | `/class/join` | 加入班级 `{code}` |
| POST | `/class/leave` | 退出班级 |
| GET | `/class/mine` | 我的班级列表 |
| GET | `/class/:id/members` | 班级成员 |
| DELETE | `/class/:id/members/:userId` | 移除成员（老师） |

## 跟读评测（核心）

### POST `/reading/evaluate`
form-data：
- `file`：录音文件（mp3）
- `refType`：`word` \| `lesson` \| `bookPage`
- `refId`：内容 ID（也可只传 refText）
- `refText`：跟读原文（可选，缺省时按 refType+refId 取库）
- `refTitle`、`assignmentId`：可选

> **错词本复习场景**：错词不一定还在内容库里，此时传 `refType=word`、`refId=0`、`refText=单词原文` 即可正常评测。
> 后端优先级：`refText` 非空时直接用；为空时才按 `refType+refId` 从库里取。

返回：
```json
{
  "id": 12,
  "score": 86.5,
  "accuracy": 88.2,
  "fluency": 85.0,
  "completeness": 100,
  "words": [
    { "word": "This", "score": 92, "matchTag": 0 },
    { "word": "family", "score": 41, "matchTag": 3 }
  ],
  "wrongWords": ["family"],
  "audioUrl": "https://.../static/audio/xxx.mp3",
  "mocked": false
}
```

`matchTag`：0 正常 / 1 漏读 / 2 多读 / 3 错读。前端配色建议：
- `matchTag=1` → 灰色删除线
- `matchTag=2` 或 `score<75` → 橙色
- `matchTag=3` 或 `score<60` → 红色波浪线

## 相关配置项（.env）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `MOCK_SOE` | `true` | `true` 时返回模拟评分，无需腾讯云密钥即可跑通流程；上线改 `false` |
| `SOE_WORD_SCORE_THRESHOLD` | `60` | 单词发音分低于此值判为「需纠正」 |
| `DAILY_LIMIT` | `0` | 每个学生每天最多跟读次数，`0` 表示不限；用于控制 SOE 费用。超限返回 403 `今日练习次数已达上限` |
| `TEACHER_INVITE_CODE` | `teacher2026` | 学生升级为老师所需的邀请码 |
| `ADMIN_USER` / `ADMIN_PASS` | `admin` / `admin123` | Web 管理后台账号，**上线前务必修改** |
