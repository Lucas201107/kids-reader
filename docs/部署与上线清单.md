## 二、部署文件说明（deploy/ 目录已备好）

| 文件 | 用途 |
| --- | --- |
| `deploy/deploy.sh` | **一键部署/更新**：备份 → 装依赖 → 同步表结构 → 编译 → 重启 |
| `deploy/backup.sh` | 数据库备份（SQLite 在线安全备份），可挂 crontab 每天自动跑 |
| `deploy/nginx.conf` | Nginx 配置：HTTPS + 静态音频目录 + 上传体积限制 |
| `deploy/ecosystem.config.js` | PM2 进程守护（含日志轮转、内存重启、单进程模式） |
| `deploy/.env.production.example` | 生产环境变量模板（含每项怎么填的注释） |
| `deploy/Dockerfile` + `docker-compose.yml` | 容器化部署方案（可选） |

## 三、方式 A：裸机 + PM2（推荐）

```bash
# 1. 装环境
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx sqlite3
sudo npm i -g pm2

# 2. 上传代码到 /opt/kids-reader（用 scp / git / 宝塔面板都行）
sudo mkdir -p /opt/kids-reader /var/log/kids-reader
cd /opt/kids-reader
# 确保 deploy/ 与 server/ 都在这个目录下

# 3. 写生产配置
cp deploy/.env.production.example server/.env
vim server/.env          # 按注释填写：域名、微信、腾讯云、密码、DAILY_LIMIT

# 4. 一键部署（首次带 SEED=yes 导入种子内容）
SEED=yes bash deploy/deploy.sh

# 5. 开机自启
pm2 startup && pm2 save

# 6. 验证
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3000/admin/index.html   # 应为 200
```

之后每次更新代码，只需 `bash deploy/deploy.sh`。

> **为什么 PM2 用单进程**：数据库默认是 SQLite，多进程并发写会锁冲突。配置里已固定 `exec_mode: 'fork'`。若改用 MySQL，可改成 cluster。

## 四、方式 B：Docker（可选）

```bash
cp deploy/.env.production.example server/.env
vim server/.env

cd deploy
docker compose up -d --build
docker compose exec api npx ts-node seeds/seed.ts   # 首次导入种子数据
docker compose logs -f api
```

数据库与上传文件都在命名卷里，容器重建不丢数据。**但 `docker compose down -v` 会删卷，先备份。**

## 五、Nginx + HTTPS

用 `deploy/nginx.conf`，只需改 3 处：域名（3 个）、证书路径、上传目录路径。

```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/kids-reader
sudo vim /etc/nginx/sites-available/kids-reader
sudo ln -s /etc/nginx/sites-available/kids-reader /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

配置要点（已包含）：
- `client_max_body_size 20m` —— 录音上传必需
- `/static/` 直接由 Nginx 提供音频与图片 —— 同时让腾讯云 SOE 能取到音频 URL
- `proxy_read_timeout 120s` —— 发音评测是同步调用，超时要给足

## 六、小程序端配置

1. 修改 `miniprogram/utils/api.js` 顶部，把两处 `api.example.com` 换成你的域名：
   ```js
   const ENV_BASE_URL = {
     develop: 'http://localhost:3000',      // 开发者工具
     trial:   'https://api.你的域名.com',    // 体验版
     release: 'https://api.你的域名.com',    // 正式版
   };
   ```
   已按运行环境自动切换，无需手动改来改去。
2. 微信公众平台 → 开发管理 → 开发设置 → 服务器域名，三处都填 `https://api.你的域名.com`：
   - request 合法域名
   - uploadFile 合法域名
   - downloadFile 合法域名
3. 上传体验版 → 把班级成员加为体验成员。**班级内部使用体验版完全够用，无需提交审核。**

## 七、数据备份（重要）

SQLite 是单文件，一定要开自动备份：

```bash
# 手动测一次
bash deploy/backup.sh

# 挂到 crontab：每天凌晨 3 点备份，每周日额外打包音频
crontab -e
0 3 * * * /bin/bash /opt/kids-reader/deploy/backup.sh >> /var/log/kids-reader/backup.log 2>&1
0 4 * * 0 WITH_UPLOADS=yes /bin/bash /opt/kids-reader/deploy/backup.sh >> /var/log/kids-reader/backup.log 2>&1
```

脚本会优先用 `sqlite3 .backup`（在线安全备份，服务运行中也一致），没装 sqlite3 时退化为文件复制并给出提示。默认保留 30 天。

## 九、成本估算（一个班 40 人）

| 项目 | 费用 |
| --- | --- |
| 云服务器 2C2G | 约 60-100 元/月（新用户首年更低） |
| 域名 + 备案 | 约 30-60 元/年 |
| SSL 证书 | 0（免费证书） |
| SOE 发音评测 | 约 0.01-0.03 元/次。40 人 × 每天 20 次 × 30 天 ≈ 2.4 万次 ≈ 240-720 元/月 |
| OCR | 免费额度通常够用 |

> **控费建议**：生产配置里设 `DAILY_LIMIT=20`，超限小程序会提示「今日练习次数已达上限」，避免费用失控。

## 十、常见故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 小程序报「网络异常」 | 域名未配 request 合法域名，或证书无效；开发者工具可临时勾选「不校验合法域名」 |
| 跟读一直失败 | `PUBLIC_BASE_URL` 不是公网 HTTPS 地址，腾讯云 SOE 取不到音频；检查 Nginx `/static/` 是否可访问 |
| 评测返回 `mocked: true` | `.env` 里 `MOCK_SOE` 还是 `true`，或腾讯云密钥没填对 |
| 上传大文件 413 | Nginx `client_max_body_size` 没生效，`nginx -t` 后 reload |
| pm2 启动后立刻退出 | 看 `/var/log/kids-reader/error.log`；常见是 `.env` 缺 `DATABASE_URL` |
| 数据库被锁 | 用了 cluster 多进程；改回 `exec_mode: 'fork'` |
| 换了服务器数据没了 | 没备份也没迁移 `server/prisma/*.db` 与 `uploads/` |
