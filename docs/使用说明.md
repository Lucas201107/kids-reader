# 使用说明（老师 & 学生）

## 一、老师操作流程

### 1. 首次进入（1 分钟）
1. 打开小程序 → 填昵称 → 身份选「老师」→ 填教师邀请码（默认 `teacher2026`，可让管理员在服务器 `.env` 里改）
2. 底部「我的」→ 找到「老师端」入口
3. 「班级」标签 → 填班级名称（如"三年级二班"）→ 选年级 → 创建
4. 创建后会显示 **6 位班级码**（如 `4ZAEUU`），点「复制」发给学生

### 2. 准备内容（三种方式，按内容量选）
| 场景 | 做法 |
| --- | --- |
| 少量单词 | 老师端 →「录入」→ 单词 → 每行一个「单词 中文」→ 保存 |
| 整册单词表 | 电脑打开 `http://你的域名/admin/index.html` → 下载导入模板 → 填好后导入 |
| 课本/绘本拍照 | 管理后台 →「图片识别」→ 上传照片 → 识别出文本 → 复制到课文/绘本里 |

### 3. 布置任务
老师端 →「布置」→ 选班级 → 填标题（如"Unit 3 单词跟读"）→ 选类型 → 勾选要练的内容（可多选）→ 布置任务。
学生首页会立刻出现「待完成任务」，点进去可以一项一项跟读。

### 4. 看数据
老师端 →「数据」→ 选班级，可以看到：
- 活跃人数 / 跟读总次数 / 全班平均分
- **高频错词榜**：全班都读错的词，下次课可以重点讲
- 学生排行：谁练得多、谁得分高

> 建议：每周用高频错词榜挑 5-10 个词做课堂带读，效果最明显。

## 二、学生操作流程

1. 打开小程序 → 填昵称 → 选「学生」→ 选年级 → 进入
2. 首页输入老师给的 6 位班级码 → 加入班级
3. 选择练习内容：
   - **绘本**：点绘本 → 从第一页开始，逐页跟读
   - **课文**：点课文 → 整篇一起读
   - **单词**：按年级筛选，一个一个读
   - **错词本**：只练以前读错的词
4. 跟读方法：
   - 先点「听范读」听一遍（如果有示范音频）
   - 点蓝色圆按钮开始录音 → 读完点一下结束
   - 稍等 1-2 秒出分数
5. 看结果：
   - **绿色** = 读得不错
   - **橙色** = 发音需要再注意
   - **红色波浪线** = 读错了
   - **灰色删除线** = 漏读了这个词
   - 点「听我的」可以回听自己的录音，和范读对比
   - 点「再练一次」重新录；读错的词会自动进错词本
6. 错词本：点「练一练」直接重练该词；**长按单词**可以把它移出错词本（已经掌握的词）

## 三、常见问题

**Q：孩子读得挺好，分数却不高？**
A：检查录音环境——嘈杂环境、离麦克风太远、声音太小都会影响识别。建议安静房间、手机距嘴 20-30 厘米。

**Q：跟读一次要花钱吗？**
A：真实发音评测按次计费（约几分钱一次）。开发/试用阶段可以先用模拟模式（`.env` 里 `MOCK_SOE=true`），确认流程后再开真实评测。

**Q：担心孩子一直练、费用失控怎么办？**
A：在服务器 `.env` 里设 `DAILY_LIMIT=30`（每个学生每天最多 30 次），超过后小程序会提示「今日练习次数已达上限」。默认 `0` 表示不限制。

**Q：能只给一个班用，不对外发布吗？**
A：可以。用微信开发者工具上传「体验版」，把班级学生加为体验成员即可，无需提交审核。

**Q：学生能看到别人的分数吗？**
A：学生端只能看到自己的成绩和错词本；班级排行只在老师端可见。

**Q：想换教材内容怎么办？**
A：管理后台导入新的 Excel 即可，种子数据（人教 PEP 示例词表）只是初始参考，可以随时增删。
